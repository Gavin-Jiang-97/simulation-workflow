# 调试与对比实验方法

## 控制变量法

无线通信系统同时受非理想扰动、信道、导频等多种变量影响。如果每条曲线看到的随机样本不同，微小的性能差异就可能被蒙特卡罗随机性掩盖，甚至呈现虚假趋势。评估时应尽量让被比较的对象看到一致的变量。

| 对比什么 | 怎样保持变量一致 |
| --- | --- |
| 不同算法 | 固定种子，每次试验预先生成信道、导频和噪声，所有方法读取同一份数据 |
| 不同天线数 | 小阵列信道直接取自大阵列信道的子集 |
| 不同网格大小 | 小网格从大网格中抽取 |
| 不同 SNR | 把 SNR 放在内层循环，保证各 SNR 下信道相同；噪声用同一份单位功率样本按 SNR 缩放 |

注意事项：

- **隔离随机数流。** 如果某个方法内部也调用随机数，共用一个随机数流会让后续方法看到的样本发生偏移。因此要预先生成数据，或为信道、噪声和各方法使用独立的流。
- **确认结论时换一批种子。** 固定种子让差值更稳定，但参数可能被调到只适合这批样本。定稿前用新种子复验，并在报告中写明试验次数。
- **核对子集的几何和归一化。** 子阵列的间距、参考阵元和功率归一化要与直接生成的小阵列一致。
- **不要用曲线平滑判断收敛。** 取子集或固定信道后，各点之间相关，曲线平滑不代表绝对值已经收敛。

## 拆解法与退化法

结果异常时不要直接调参数，先定位原因：

1. **确认异常现象。** 比如曲线不单调、高 SNR 出现误差平台、结果优于理论界，或换数据后趋势反转。
2. **拆解链路。** 把链路分成信道生成、导频、估计、均衡、指标计算等模块，逐段与真值或理论值比较，定位最早出错的环节。
3. **退化到答案已知的情形。** 比如无噪声、单径、理想同步、理想先验，验证代码在这些情形下给出预期结果。
4. **逐个恢复非理想因素。** 每次只改一个因素，观察性能变化出现在哪一步。
5. **写入报告。** 问题用红色标记，修复后改为蓝色。如果这个问题反映了某种规律，记入末尾总结。

修复后要重跑受影响的结果，并检查共用同一段代码的其他实验是否也受影响。

**示例：** 射线追踪数据上的表示误差曲线不单调。排查后发现，群时延的牛顿迭代在线搜索失败后仍然无条件更新。这个问题只有逐段检查迭代过程才能看到，单看最终曲线无法定位。
