# 仿真图规范

- **图例位置：** 图例放在坐标轴外时放在图的上方，不放在下方。放在坐标轴内时，不要遮挡任何曲线。
- **图例完整：** 图例边框要完整，文字和边缘不能被裁切。
- **字号：** 缩放到最终宽度后，图中文字与正文字号（约 12 pt）相同或小一号。MATLAB 默认字号通常偏小。
- **论文风格：** 不加子图标题，在图注中用左图、右图来指代。双子图共用一个放在上方的图例。

## MATLAB 导出 PDF

MATLAB 导出矢量 PDF 时，LaTeX 或 Times 字体的图例文字实际绘制得比测量宽度更宽，会溢出图例边框，并与相邻列重叠。

- 图例使用默认无衬线字体和 tex 解释器。
- 多列图例用多个并排的单列图例拼成，只画一个边框。
- 输出 PDF 时，要检查 PDF 本身，而不是 MATLAB 导出的 PNG。可以用 `pdftoppm` 临时渲染来查看，看完删除。
