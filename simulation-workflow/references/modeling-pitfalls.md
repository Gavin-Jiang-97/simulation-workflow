# 建模与方案选择的常见问题

## 算法模型与工具箱模型不匹配

算法设计所基于的模型，可能与工具箱或函数内置的模型不一致。这类错误不会报错，只会表现为性能变差或趋势异常，所以调用前要主动核对。

**示例：** 射线追踪信道模型中空域导向矢量的参考坐标，与 RT 工具箱内部的定义不一致。

调用工具箱前，对照其文档或源码核对以下约定：

| 类别 | 核对内容 |
| --- | --- |
| 坐标与角度 | 坐标系方向，方位角和俯仰角的定义，弧度还是角度 |
| 阵列 | 参考阵元或相位中心，阵元间距和排列顺序，极化 |
| 相位与时延 | 相位符号，时延的参考点，载波相位是否已包含 |
| 维度与功率 | 矩阵维度顺序，收发方向，功率和路径损耗的归一化方式 |

**验证方法：** 取单径或少量路径，用算法模型按工具箱输出的路径参数重建信道，再与工具箱生成的信道比较。两者应在数值误差范围内一致。不一致时，先解决模型问题，再评估算法。

## 处理方式取决于边界条件

很多处理没有绝对的对错，只有在当前边界条件下哪个更合适。选择前先明确系统实际能获得哪些信息，并在报告中写明选择及其依据。边界条件变化时，要重新判断。

**示例：** 信道估计中信道协方差矩阵的获取方式。

| 可获得的信息 | 协方差矩阵的获取方式 |
| --- | --- |
| 只有统计模型 | 随机生成信道样本，求统计平均 |
| 有位置相关的先验 | 使用具体位置下功率谱对应的协方差 |
| 只有某个区域内的先验 | 对区域内多个位置对应的协方差求平均 |

## 方案利弊要放在同一条件下权衡

对一个环节有利的设计，可能损害另一个环节。评估方案时，要同时看理想条件和非理想条件，不要只凭理想条件下的结果下结论。把各方案占优的条件记入报告末尾的总结。

**示例：** 信道的多径丰富程度。

| 多径数 | 数据传输 | 信道估计 |
| --- | --- | --- |
| 较多 | 空间自由度高，传输容量更高 | 稀疏性低，估计误差更大 |
| 较少 | 空间自由度低，传输容量受限 | 稀疏性高，估计误差更小 |
