# simulation-workflow

一个 Agent Skill，用于规范科研仿真的代码注释、Results 报告、图片输出和Debug方法。它的目的是让作者能快速审核结果，并减少 AI 写代码与调试时的常见错误。示例来自无线通信仿真，方法同样适用于其他领域。

## 内容

- **代码注释：** 主体代码注释函数、运算模块和关键变量，验证和 Debug 代码简化注释。
- **Results 报告：** 把控篇幅，嵌入仿真图，用 LaTeX 写公式，用树状图展示函数关系，用红蓝标记问题和已解决的结果，并在末尾持续维护规律总结。
- **图片与 token：** 同一张图只保留一种格式；文字已提供所需信息时，AI 不再查看图片。
- **调试方法：** 控制变量法、拆解法和退化法。
- **建模与方案选择：** 核对算法模型与工具箱模型是否匹配，根据边界条件选择处理方式，并权衡方案的利弊。
- **码文合一：** 代码与仿真文档或计划文档保持对应；没有相应文档时，先询问作者是否生成计划文档。
