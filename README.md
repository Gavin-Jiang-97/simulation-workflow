# simulation-workflow

一个 Claude Skill，用于规范科研仿真的代码注释、Results 报告、图片输出和调试方法。它的目的是让作者能快速审核结果，并减少 AI 写代码与调试时的常见错误。示例来自无线通信仿真，方法同样适用于其他领域。

## 内容

- **代码注释：** 主体代码注释函数、运算模块和关键变量，验证和 Debug 代码简化注释。
- **Results 报告：** 把控篇幅，嵌入仿真图，用 LaTeX 写公式，用树状图展示函数关系，用红蓝标记问题和已解决的结果，并在末尾持续维护规律总结。
- **图片与 token：** 同一张图只保留一种格式；文字已提供所需信息时，AI 不再查看图片。
- **调试方法：** 控制变量法、拆解法和退化法。

## 安装

把 `simulation-workflow/` 文件夹复制到 `~/.claude/skills/`，或打包后上传到 Claude 的 Skill 库。
